# BB-75: проверка Mini App UI

Работа начата от сохранённой BB-73 `9fbbc0be2e1090ba7f23ef263532164cce16aa74`.
На момент создания worktree локальная BB-73 и `origin/bb-73-existing-db-migration`
указывали на этот SHA. Использована отдельная ветка `bb-75-miniapp-ui-tests`.
Проверка GitHub metadata подтвердила `visibility: private`.

## Подтверждённые ошибки и исправления

| Ошибка | Воспроизведение | Исправление |
| --- | --- | --- |
| Повторное создание записи | Два нажатия до ответа отправляли два `booking-create` | Кнопка блокируется до завершения запроса и восстанавливается после ошибки |
| Повторное подтверждение | Два нажатия отправляли два `bookings-write` | Действия карточки блокируются на время подтверждения |
| Повторная публикация слота | Два нажатия отправляли два `slots-write` | Состояние `publishing` и блокировка кнопки |
| Пустой каталог | Успешный ответ с пустым списком оставлял пустой экран | Текст `Услуг пока нет` |
| Ошибка профиля мастера | После ошибки загрузки оставалось старое имя | В профиле отображается сообщение API об ошибке |
| Переполнение календаря | Ячейки фиксированной ширины выходили за экран 320 px | Гибкие колонки и размеры ячеек |
| Переполнение каталога и результата записи | Длинное название услуги расширяло страницу | Ограничение flex-элементов, ширины тегов и перенос значений |
| Нижняя навигация на 320 px | Панель начиналась с x = -6.5; указатель профиля выходил за панель | Адаптивная ширина панели и процентные размеры указателя |
| Выбор города не срабатывал | Анимация нажатия создавала stacking context, и карточка перехватывала клик по пункту списка | Явный z-index контейнера dropdown |
| Фоновая прокрутка модалки | Wheel за открытой модалкой менял `scrollY` с 0 на 700 | Блокировка overflow тела страницы с восстановлением при закрытии |

Также удалены дублирующийся `class` и устаревший inline-обработчик кнопки публикации.
Существующий JS-обработчик подключён к одному явному классу.
Кнопки выбора причины в модалках блокируются сразу после выбора.
Модальное окно ограничено шириной и высотой viewport, длинное содержимое можно прокрутить.
Эти дополнительные изменения проверены браузерными регрессиями.

## Покрытие

Проверяются регистрация через `ensure`, загрузка и изменение профиля модели,
профиль и адрес мастера, каталог, выбор услуги, поиск слотов, календарь,
валидация формы и публикация слота, создание записи, подтверждение, отклонение,
отмена моделью, отмена мастером, удаление свободного слота и архив.

Дополнительно проверяются загрузка, пустые списки, сетевой сбой, HTTP 401 и 500,
повтор после ошибки, повреждённый JSON, повторные нажатия, длинные данные,
PNG-аватар, неверный MIME, превышение лимита размера и ошибка API аватара.
Навигация, Escape, модальные окна, фоновая прокрутка и отсутствие горизонтального
переполнения проверяются на мобильных размерах от 320 до 430 px.

Telegram mock покрывает `ready`, `expand`, haptics, popup, безопасный перехват ссылки
поддержки и отсутствие Telegram identity. Вызовы уведомлений заканчиваются в MockAPI.
Они не являются подтверждением настоящей доставки.

## Результаты

Проверено 9 ноября 2026 года. Полный прогон BB-75: **34 passed**, 55.06 s,
из них 33 браузерных сценария и 1 HTTP-проверка изоляции mock-сервера.
Существующие проверки BB-69: **3/3** офлайн-проверки сборки и **9/9** проверок
карточек записей. Проверки синтаксиса изменённых JS и `git diff --check` прошли.

Окружение: macOS arm64, Python 3.13.0, Playwright 1.64.1, pytest 9.2.0,
Google Chrome 156.0.8078.80. Включены `is_mobile` и `has_touch`.
Геометрия основных экранов проверена на 320×568, 360×640, 390×844 и 430×932.
Скриншоты узкого календаря, профиля, модалки и результата записи просмотрены визуально.

JUnit-результаты, PNG и traces сохраняются в локальных артефактах тестов.
Команды воспроизведения и описание изоляции находятся в
[tests/bb75/README.md](../tests/bb75/README.md).

## Непроверенная интеграция и зависимости

Реальная Telegram-доставка, запуск из меню бота, подпись и срок действия `initData`,
реальная авторизация Supabase, RLS и серверные гонки не проверялись.
Реальное хранилище аватаров, ограничения обработки изображений и доступность URL
проверяются отдельно на согласованном интеграционном окружении.

Не проверялись физические Telegram WebView на iOS и Android, системная клавиатура,
safe area и нативные жесты Back. Для локального повтора нужны Python, зависимости
из `tests/bb75/requirements.txt` и установленный Chrome. Облачные сервисы не нужны.

SQL, Edge Functions, webhook, production builder и release-инфраструктура не изменены.
Main, BB-73, BB-74 и чужие worktrees не переключались и не редактировались.
